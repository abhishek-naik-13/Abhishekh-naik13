ABHISHEK NAIK — DEVOPS PORTFOLIO

Files:
- index.html       Main portfolio page
- style.css        Responsive styling
- script.js        Mobile navigation and current year
- assets/abhishek-profile.jpeg  Your profile photo

PREVIEW LOCALLY:
1. Keep the assets folder beside index.html.
2. Double-click index.html, or use VS Code Live Server.

PUBLISH WITH GITHUB PAGES:
1. Create/open your GitHub repository.
2. Upload index.html, style.css, script.js, and the entire assets folder.
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, choose main and / (root), then Save.
5. Wait for the Pages URL to appear in Settings > Pages.

BEFORE PUBLISHING:
- Check that the email, LinkedIn and GitHub URLs are correct.
- Project cards currently link to your GitHub profile. Replace each with the
  exact repository URL once those project repositories are available.
- Skill progress bars are illustrative. Adjust or remove them to accurately
  reflect your skills.
- Google Fonts loads from the internet; system fonts will be used if offline.
